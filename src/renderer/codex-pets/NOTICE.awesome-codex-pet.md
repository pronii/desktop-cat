# Awesome Codex Pet Asset Notice

The pet sprite packages in this directory were imported from:
https://github.com/legeling/awesome-codex-pet

Imported source commit: 7b0892cc5e8ee63188f5d3bdb3c11b488a6bd793

Each pet folder keeps the upstream pet.json, submission.json, and spritesheet.webp files. Runtime discovery reads submission.json so per-pet author and license metadata remains visible in the app model list.
